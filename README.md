# 📧 Email Spam Detection

A machine learning-based web application built using **Python and Django** to classify email messages as spam or legitimate. This project demonstrates the application of machine learning and text classification in detecting unwanted messages.

## 🚀 Live Demo

[**View Live Application →**](https://spam-detector-3le4.onrender.com/)

## ✨ Features
- Classifies messages as spam or legitimate.
- Machine learning-based text classification.
- Simple and user-friendly web interface.
- Web application deployed on Render.

## 🛠️ Tech Stack
- **Language:** Python
- **Framework:** Django
- **Machine Learning:** Scikit-learn
- **Data Processing:** Pandas
- **Frontend:** HTML, CSS

## 💻 Run Locally

```bash
git clone https://github.com/zombie-132/Spam-Detector.git
cd Spam-Detector

python3 -m venv venv
source venv/bin/activate

pip install -r requirements.txt
python manage.py runserver
```
